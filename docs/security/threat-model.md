# MVP 威胁模型

## 范围与原则

本模型覆盖聊天文件从用户选择、解析、加密落库、统计、脱敏预览到模型请求和复制建议的完整链路。保护目标是聊天原文、联系人身份、数据库密钥、模型凭据及用户对上传/发送动作的控制权。

默认原则：本地优先、最小授权、显式确认、日志不含敏感内容、失败时保守停止。应用不申请 Root、无障碍、通讯录或第三方应用私有目录权限。

## 资产、攻击面与缓解

| 攻击面 | 主要风险 | 当前缓解 | 剩余风险与处置 |
|---|---|---|---|
| 本机聊天文件 | 读取错误文件、路径泄露、确认前持久化 | 使用 SAF `OpenDocument` 只读流；先展示文件元数据、身份和问题；不保存原路径 | 文件提供方仍可返回伪造内容；解析器严格校验并允许取消 |
| 解析与导入 | 畸形数据、部分导入、重复导入 | JSON/JSONL 校验；fatal 阻断；repository 事务写入；来源哈希保证重导幂等 | 当前 UI 可跳过 JSONL 非致命坏行，确认页必须明确显示 warning |
| 本地数据库 | 数据库文件被复制、密钥硬编码、残留数据 | SQLCipher；随机口令由 Android Keystore 包装；无代码内密钥；联系人级删除使用级联事务 | 已解锁设备或运行中进程仍能访问明文；依赖系统锁屏与 Android 沙箱 |
| 备份与迁移 | 云备份或换机把聊天数据带出设备 | `allowBackup=false`、`fullBackupContent=false`，data extraction rules 排除 root 域 | OEM 可能实现额外迁移能力；发布验收需在目标 OEM 复核 |
| 日志与崩溃 | 原文、API Key、Authorization、URL token 进入 logcat | 生产代码不记录请求体/密钥；provider logger 只接收固定事件名；配置对象 `toString()` 固定把 Key 显示为 `[REDACTED]`；对 UI 暴露稳定的分类错误 | Throwable cause、第三方网络栈和系统组件仍可能在内存中持有底层错误；任何未来日志或崩溃上报都不得记录完整异常链、请求/响应或配置对象字段 |
| 剪贴板 | 其他应用或系统历史读取回复文本 | 仅用户点击“复制”后写入；Snackbar 提示剪贴板隐私；不复制聊天原文 | Android 版本和输入法可能保留剪贴板历史；用户需主动清理 |
| 网络传输 | 明文 HTTP、中间人、错误 endpoint | manifest 和 network security config 禁止明文；第一版代码固定 DeepSeek 官方 `/models` 与 Chat Completions HTTPS 地址；请求前展示供应商和上传范围 | 受信任 CA、DeepSeek 及其基础设施仍可看到请求数据；发布前仍需复核证书、域名和地区策略 |
| 模型供应商 | 数据留存、二次训练、跨境处理、输出误导 | 仅支持 DeepSeek 官方服务；Chat Completions 只在用户确认脱敏预览后调用；建议展示意图/风险且不自动发送 | DeepSeek 作为第三方可见鉴权账户、所选模型、结构化提示和已确认的脱敏聊天内容；其留存、训练、人员访问和跨境处理不由本应用控制 |
| 导出组件 | 外部应用伪造 Intent 或直接调用内部组件 | 仅 Launcher Activity 因系统要求 `exported=true`；无其他 exported 组件；SAF URI 由系统选择器返回 | Activity 可被启动但不会自动读取、上传或发送数据 |
| Root/调试环境 | 绕过沙箱、读取内存或数据库、注入证书 | 不声称在 Root 设备上保密；不启用 Root/无障碍；发布构建关闭调试 | Root 或被攻陷系统属于信任边界外，应在产品隐私说明中明确 |

## 数据流与信任边界

1. 系统文件选择器把临时只读 URI 交给应用。
2. 解析器在应用进程内生成预览；用户确认后 repository 才写入加密数据库。
3. 统计引擎只读取领域消息并在本机计算。
4. 回复页把当前消息加入最近上下文，先经 `ContextRedactor` 替换链接、邮箱和手机号，再展示预览。
5. 用户点击“确认生成”后才允许 provider 调用；未配置或失败时停留在预览，由用户显式选择重试、取消或本地规则建议。
6. 建议只能由用户主动复制，应用没有发送通道。

## DeepSeek 凭据与请求边界

### 本机保存

- API Key 由 Android Keystore 中独立 alias 的 AES-GCM 密钥加密。应用私有 `SharedPreferences` 只保存模型 ID、密文、IV 和非敏感格式版本，不保存 Key 明文。
- 模型设置页不回显已保存 Key；只有用户输入的新候选 Key 会在当前进程内短暂存在，验证成功且用户点击“保存并启用”后才写入。
- `clear()` 先清除 `SharedPreferences` 中本配置的全部字段，再删除独立 Keystore alias。若偏好清除失败，会尝试恢复清除前快照并报告稳定错误；若偏好已清除但 alias 删除失败，配置对外已不可读取，控制器会重新读取存储状态并按“未配置”对账，同时报告清除失败。残留 alias 不含可直接导出的 Key 明文，但仍需在后续重试或卸载时清理。

### 在线请求

- `GET https://api.deepseek.com/models` 只携带 Bearer 鉴权并读取官方模型目录，不读取或上传聊天消息。
- Chat Completions 只在用户看到“将上传的上下文”并点击“确认生成”后调用。上传范围是预览中列出的当前消息和聊天上下文，经 `ContextRedactor` 替换手机号、邮箱和 URL；原文件路径、应用内真实身份映射和 API Key 不进入消息正文。
- 未配置时不会创建在线服务；配置解析中不会误判为未配置；配置保存、清除或切换后会刷新 provider。每次预览固定使用当时解析出的 provider snapshot，旧配置解析或旧在线请求不能覆盖较新的配置代次。
- 在线错误不会自动降级。预览和输入保持可见，用户必须显式重试、取消或点击“使用本地建议”。

### 日志、异常与字符串表示

- 不记录 Authorization、API Key、请求体、响应体或聊天样例；provider logger 只能接收固定的开始/成功/失败事件，不接收动态错误文本。
- `DeepSeekConfiguration.toString()` 永远隐藏 Key，UI state 和 provider 标签不包含 Key；对外异常消息只暴露认证、余额、限流、超时、服务不可用或格式错误等固定类别。
- 底层异常 cause 可能包含设备、网络或第三方库生成的细节。当前代码不把它写入日志；未来接入日志、分析或崩溃 SDK 时不得调用完整异常 `toString()`、打印 stack trace 或序列化 request/response。

## 剩余风险

- Root、调试器、内存转储、注入框架或已攻陷系统可以绕过 Android 沙箱，读取运行时明文或操纵 Keystore 调用；本应用不承诺在此环境下保密。
- 用户输入 Key 时，系统键盘、无障碍服务、屏幕录制/投屏、系统截图和肩窥可能看到屏幕或输入事件；密码遮罩只能降低普通旁观风险。
- 用户复制回复后，系统剪贴板、输入法或其他有权限的应用可能保留内容；应用只在用户点击复制时写入并提示风险。
- 脱敏规则只能处理已覆盖的手机号、邮箱和 URL，不能保证识别姓名、暗语、地址、罕见账号或从上下文推断出的身份。用户必须在确认页人工核对。
- DeepSeek、受信任 CA、系统网络栈和设备厂商属于外部信任边界；服务端数据治理需以发布时的隐私政策和供应商条款再次评估。

## 发布前复核项

- 检查 manifest 最小授权、备份策略和明文流量禁用状态。
- 对固定 DeepSeek 官方 endpoint 做证书、日志、密钥存储和供应商条款专项审查。
- 在目标 Android/OEM 上验证删除、备份、剪贴板提示和 Root 风险文案。
- 任何新增分析 SDK、崩溃 SDK、字体或模型依赖都必须重新评估数据流。
